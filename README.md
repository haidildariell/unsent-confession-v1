Entry for [Unsent: The Micro-Confession Sprint](https://make.fun/bounty/u-boothlord-unsent-the-micro-confession-sprint-8c6596ba) on make.fun.

`main.py` writes one two-part micro-confession to `/output/entry.txt`:
a `To:` line naming who it was meant for, then the unsent message
itself, one line exactly as typed, with no explanation after it.

Run it with:

```sh
python3 main.py
```
